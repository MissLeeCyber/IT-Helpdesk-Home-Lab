# IT Help Desk Home Lab

Hands-on IT support and systems administration home lab designed to build practical skills for an entry-level IT Help Desk / IT Support role.

## About This Lab

This project documents my progression through a hands-on IT home lab environment, including Windows administration, troubleshooting, networking, Active Directory, PowerShell, and cybersecurity fundamentals.

The goal is to develop practical troubleshooting and system administration skills through realistic IT support scenarios rather than relying solely on theoretical coursework.

## Lab Environment

* **Virtualization:** Oracle VirtualBox
* **Server:** Windows Server 2025
* **Client:** Windows 11
* **Domain:** LEE.LOCAL
