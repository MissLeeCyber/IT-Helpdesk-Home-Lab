## Day 2 (09/25/2026) – Windows Administration & Troubleshooting

### Environment

- Server: LCS-DC01

### Topics Practiced

#### 1. Windows User Accounts

- Reviewed Administrator vs. Standard User permissions.
- Learned why least-privilege access is important in IT environments.

#### 2. Task Manager

- Reviewed Processes, Performance, Users, and Startup Apps.
- Learned how to identify processes consuming excessive CPU, memory, disk, or network resources.
- Practiced using Task Manager as an initial troubleshooting tool.

#### 3. Device Manager

- Reviewed installed hardware and network adapters.
- Learned how Windows uses device drivers.
- Learned how yellow warning icons can indicate hardware or driver problems.

#### 4. Windows Services

- Opened services.msc.
- Reviewed the Print Spooler service.
- Learned how Windows services operate in the background.

#### 5. Event Viewer

- Opened eventvwr.msc.
- Reviewed Windows Logs, including Application and System logs.
- Learned how Event Viewer can be used to investigate application crashes, system errors, and service problems.

### Help Desk Troubleshooting Exercises

- Ticket 001: Slow computer
- Ticket 002: Printer not working
- Ticket 003: Wi-Fi not working
- Ticket 004: Application crashing
- Ticket 005: Windows startup error

### Troubleshooting Concepts Learned

- Gather information before making changes.
- Reproduce the reported problem when possible.
- Determine the scope of an issue: one user vs. multiple users.
- Use evidence rather than guessing.
- Verify that a fix actually resolved the problem.
- Distinguish between diagnostic tools and remediation tools.
