# Ticket 001 – Slow Computer

## User Report

**User:** Sarah  
**Issue:** Computer is extremely slow.

Sarah reports that her computer has become unusually slow and is taking longer than normal to perform tasks.

## Initial Assessment

The first step is to gather evidence rather than immediately assuming what is causing the problem.

## Troubleshooting Steps

### 1. Open Task Manager

Opened Task Manager and reviewed:

- CPU utilization
- Memory utilization
- Disk utilization
- Running processes
- Startup applications

### 2. Identify Resource Usage

Looked for processes consuming unusually high amounts of CPU, memory, or disk resources.

A high resource-usage process should not automatically be assumed to be the cause. The process should be identified and evaluated before taking action.

### 3. Evaluate the Process

Determined whether the high-resource process was:

- Required by Windows
- Required by the user
- Associated with a known application
- Safe to close

### 4. Take Appropriate Action

If an identified application was not needed and was causing excessive resource usage, the application could be closed or its process terminated.

Critical Windows processes should not be terminated without understanding their purpose.

### 5. Verify the Result

After taking corrective action:

- Rechecked CPU, memory, and disk utilization.
- Confirmed whether system responsiveness improved.
- Verified that the reported issue was resolved.

## Troubleshooting Method

**Symptom → Evidence → Hypothesis → Controlled Action → Verification**

## Resolution

The exact cause and resolution would depend on the resource usage and evidence found during troubleshooting.

## Skills Demonstrated

- Task Manager
- Windows troubleshooting
- Resource monitoring
- Process identification
- Evidence-based troubleshooting
- Verification after remediation

## Key Takeaway

A slow computer does not automatically mean high CPU usage is the problem. CPU, memory, disk, running processes, startup applications, Windows updates, security scans, and hardware issues should all be considered during troubleshooting.
